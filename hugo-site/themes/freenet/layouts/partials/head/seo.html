{{/* Search and link-preview metadata: meta description, canonical URL, Open Graph and Twitter card. URLs are built from params.canonicalBaseURL rather than .Permalink or absURL. The Freenet-hosted mirror (cargo make build-freenet) builds with a relative baseURL (/v1/contract/web//), where .Permalink is not an absolute URL; canonical, og:url and og:image all require one, and every copy of a page should name freenet.org as the canonical anyway. Stripping the baseURL's path from .RelPermalink gives the site-relative path under either build. Description: front matter `description`, else front matter `summary`, else the generated summary for regular pages (a section's is its child list), else params.description. Headings are dropped from the summary first: plainify alone runs "Purpose" into the paragraph after it. Image: front matter `image` (a static path or absolute URL) with optional imageWidth/imageHeight, else params.ogImage and its dimensions. */}} {{ $base := site.Params.canonicalBaseURL | default "https://freenet.org/" }} {{ $path := strings.TrimPrefix (urls.Parse site.BaseURL).Path .RelPermalink | strings.TrimPrefix "/" }} {{ $url := printf "%s%s" $base $path }} {{ $desc := .Description | default .Params.summary }} {{ if and (not $desc) .IsPage }} {{ $desc = .Summary | replaceRE `(?s)]*>.*?` " " | plainify | htmlUnescape | replaceRE `\s+` " " | strings.TrimSpace | truncate 160 }} {{ end }} {{ $desc = $desc | default site.Params.description }} {{ $img := site.Params.ogImage }} {{ $imgW := site.Params.ogImageWidth }} {{ $imgH := site.Params.ogImageHeight }} {{ with .Params.image }} {{ $img = . }} {{ $imgW = $.Params.imageWidth }} {{ $imgH = $.Params.imageHeight }} {{ end }} {{ if and $img (not (hasPrefix $img "http")) }} {{ $img = printf "%s%s" $base (strings.TrimPrefix "/" $img) }} {{ end }} {{ $title := cond .IsHome (printf "%s: %s" site.Title .Title) .Title }} {{ with $img }} {{ with $imgW }}{{ end }} {{ with $imgH }}{{ end }} {{ else }} {{ end }}
